# Pedido de P4 para P5

## Integración de pruebas y tipos de P4

Para poder cerrar T009-41 a T009-46 con los comandos obligatorios, incluir en `tarea3/tsconfig.json`:

- `servidor-mcp/**/*.ts`
- `agente/**/*.ts`

Asimismo, ampliar el script `test` de `tarea3/package.json` para ejecutar `servidor-mcp/**/*.test.ts` además de `pruebas-e2e/**/*.test.ts`.

No se solicita cambiar dependencias ni contratos.
