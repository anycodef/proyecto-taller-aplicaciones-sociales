# Skills del proyecto

Paquete versionado definido por T001-27: `nueva-migracion` y `verificacion`.
Cada carpeta contiene un `SKILL.md` con frontmatter Agent Skills.

Distribución al marketplace/plugin del proyecto: registrar esta carpeta como fuente.
Para OpenCode, la configuración del consumidor usa `skills.paths: ["./skills"]`;
la integración del marketplace queda pendiente de su dueño. Tras registrar la
fuente, reiniciar OpenCode para descubrirlas. No se modifica configuración del
harness en esta entrega.
